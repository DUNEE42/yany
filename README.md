# 言语 1.8.0：Android 个人版

言语是一个 Android 原生的 AI 陪伴聊天应用。当前版本的核心是：

> 在自己的手机上使用 DeepSeek 流式聊天，并通过本地、可追溯、可纠正的记忆系统持续记住重要事情。

应用显示名已由旧名统一为“言语”，伴侣名为“林”。为保持已有聊天、记忆和加密数据库能够直接覆盖升级，
Android 包名仍保留为 `com.xinyu.companion`。这个内部标识不面向用户，也不会改变数据目录。

## 当前能力

- 单页聊天界面，不依赖网页套壳。
- 直接连接 DeepSeek 的 OpenAI 兼容接口。
- 手机端流式显示回复，可停止生成、失败重试。
- 重试复用原用户消息，不会重复插入聊天记录。
- 对话手感可调：随机性、亲近感、回复长度和恢复默认。
- 全屏模块化设置页：模型连接、对话手感、记忆、提醒、环境感知、隐私数据和关于。
- 首次连接页只展示连接任务；连接成功后平滑展开手感、记忆、隐私和关于。
- 页面切换带方向过渡，聊天发送/停止合并为单个动作键。
- 用户向上阅读历史时不再被流式回复强行拉到底部，并提供“回到最新”。
- 记忆分组筛选固定在顶部，危险确认改为触屏更顺手的底部操作面板。
- 可选环境感知：按应用允许通知、查看最近一次前台应用、粗粒度网络城市和实时天气。
- 用户配置 SearXNG 后，可对时效问题联网搜索并显示实际引用的来源。
- 搜索前可查看并编辑实际外发搜索词；授权只对当前消息生效，不能跨消息复用。
- 通知和搜索内容经过来源、权限、敏感信息、Prompt Injection、TTL 和相关度过滤，
  默认不进入长期记忆。
- 支持用户明确设定时间与文字的本地提醒；规则使用 Android Keystore 加密保存在本机，
  到点由系统通知，重启后恢复，可随时取消。
- 本地提醒不让模型猜课程结束时间，也不把提醒文字发送给 DeepSeek 或 SearXNG。
- 数据库 v6 增加加密的计划观察事件和通知来源索引；普通通知正文不持久化。
- Provider、设置存储和会话存储通过领域端口接入，可扩展 OpenAI、Ollama 或本地模型。
- 本地安全策略区分危机、强烈痛苦和普通聊天，并处理常见否定表达。
- API Key 使用 Android Keystore + AES-GCM 加密后保存在本机。
- 聊天记录使用 Room + SQLCipher 加密保存在本机。
- 数据库 v5 增加短期摘要、原子长期记忆、证据来源、记忆任务和全文索引。
- 最近 3–5 天的短期工作记忆由最近原文和 AI 滚动摘要组成。
- 长期记忆按事实、偏好、边界、计划、事件和关系偏好保存，并记录来源、有效时间和确认状态。
- 单批最多整理 5 天、40 条完成消息或约 8000 字符，不阻塞聊天回复。
- AI 只生成记忆候选；确定性校验通过后才写库。AI 推测默认保持待确认。
- 1.6.1 增加本地写入策略：AI 自述、一次问答、记忆测试直接丢弃；当天情绪只保留为
  有期限的近期经历。
- 稳定偏好、边界和稳定事实必须同时具备用户明说证据与候选自身引用证据，才能自动生效。
- 城市、健康、财务、联系方式等敏感信息由本地规则强制进入待确认，确认前不进入画像。
- 普通事件默认 14 天、最长 30 天；计划最长 30 天，到期后自动移出上下文。
- 短期摘要改为“近期经历 / 当前状态 / 未完成话题”，无高价值内容时允许 no-op。
- 中文记忆检索拆成短词与二三元词组，避免整句无法命中；纯标点查询不再乱召回。
- 新旧事实冲突时旧事实失效并保留历史，不会被直接覆盖。
- 下一轮对话只检索相关画像、短期摘要和最多 8 条长期记忆，不把整个记忆库发送给模型。
- 提供记忆查看、手动添加、编辑、确认、拒绝、单条删除、忘记最近三天和清空全部。
- 清空全部记忆后写入检查点并暂停自动记忆，避免旧聊天立即被重新整理。
- 应用意外退出后，未完成的回复会恢复为“已中断”。
- 清空会话后旧生成任务不能覆盖下一次对话状态。
- 设置中可分别删除 API Key 和清空聊天记录。
- 首次连接会发送一次最小测试请求，成功后才保存配置。
- 诊断日志只记录耗时、结果和错误码，不记录聊天正文或 API Key。
- HTTP 200 但返回普通 JSON 时会自动兼容；网页拦截和 JSON 错误会给出明确原因。
- JSON 中的 `null`、错误字段类型和异常事件不会再暴露 Kotlin 反射错误。
- 不包含登录、支付、向量 RAG、工具调用或公共代理服务。

## 第一次使用

1. 打开言语。
2. 在“连接 DeepSeek”中输入自己的 DeepSeek API Key。
3. 模型默认填写 `deepseek-chat`；如果账号使用其他模型 ID，可以修改。
4. 点击“测试并保存”。
5. 测试成功后自动进入聊天页。
6. 打开设置中的“记忆”，可以关闭自动整理、立即整理以及查看、修改或删除记忆。
7. 打开设置中的“提醒”，先允许系统通知，再填写提醒文字和明确时间。
8. 打开设置中的“环境感知”，按需开启通知使用权、使用情况访问、粗粒度网络位置或搜索。

环境感知默认全部关闭。通知来源默认拒绝；只有用户明确允许的应用才有机会生成短期事件。
普通通知正文不会持久化，首版只保留包裹、课程和日历事件。

实时天气优先使用手动填写的城市，其次才是公网 IP 估算的粗粒度城市。原始 IP 不存储、
不写入记忆、不发送给 DeepSeek。

通用联网搜索需要填写一个启用了 JSON 输出的 HTTPS SearXNG 地址。遇到需要联网的问题时，
应用会先暂停发送并显示准备外发的搜索词，用户确认后才请求该实例；搜索结果不是用户事实，
也不会自动进入记忆。

本地提醒由用户明确设定时间，适用于“17:30 取快递”或“20:00 给家里打电话”等已知事项。
它不会从“我是大学生”推断课表，也不会读取其他应用内部内容来猜下课时间。Android 省电模式
可能让提醒晚几分钟；关闭系统通知权限后，应用会拒绝创建新提醒。

API Key 不会写进 APK，也不会发送给言语自己的服务器。聊天时，应用会通过 HTTPS 直接把必要上下文发送给：

```text
https://api.deepseek.com/chat/completions
```

开启自动记忆后，应用还会把需要整理的消息批次发送到同一个接口。DeepSeek 会看到聊天上下文和记忆整理输入，其数据保留规则以 DeepSeek 的服务条款为准。

## 安全边界

这是个人 BYOK 版本，不是公开运营版本。

- 手机 App 必须能在运行时解密 Key 才能发起请求，因此被 Root、注入或运行时内存抓取时仍存在风险。
- 建议使用单独的 DeepSeek Key，并在供应商后台设置消费限额。
- 不要把保存过个人 Key 的手机或应用数据交给不可信的人。
- 如果要做统一充值、额度控制、防刷和公开分发，必须切换到服务端代理模式。

项目中的 `server/` 保留了以后做平台服务端的实验代码，但 Android 个人版不依赖它。

## 1.8.0 本地提醒与搜索确认

- 应用显示名统一为“言语”，默认伴侣名统一为“林”。
- 为保持覆盖升级，包名、数据库文件、伴侣内部 ID 和旧加密数据身份不变。
- 新增“设置 → 提醒”：选择未来日期与时间，填写最多 120 字，保存后进入待处理列表。
- 提醒规则使用独立 Android Keystore AES-GCM 密钥加密，不写入模型上下文。
- 使用 `AlarmManager.setAndAllowWhileIdle`，不申请精确闹钟专用权限；系统可能延迟。
- 重启和覆盖升级后恢复未到期提醒；取消规则同时撤销系统闹钟。
- Android 13+ 使用标准通知权限；没有通知权限时不允许保存新提醒。
- 通知点击回到言语，并提供“知道了”动作。
- 搜索意图先显示实际外发查询词，用户可编辑、确认搜索或仅聊天；硬敏感字段确认后仍不外发。
- 搜索授权只绑定当前消息，重试和其他消息不会复用。

## 1.7.0 环境感知

- 通知来源默认全部拒绝；未允许应用只记录包名、显示名和最近出现时间。
- 只持久化包裹、课程和日历事件；普通通知正文、验证码和提示词注入文本不保存。
- 通知事件 TTL 为 24–72 小时；来源索引最多保留 30 天。
- 通知使用权撤销或来源关闭后，历史事件立即停止进入模型上下文和观察列表。
- 天气优先使用用户城市，缺失时才由公网 IP 估算城市；原始 IP 不落盘。
- SearXNG 搜索最多返回 5 条、12 秒超时；私人叙事不会以整句发送。
- 搜索结果过滤 HTML、控制字符、危险 URL 和常见 Prompt Injection。
- 回答只附加模型实际用 `[S1]`、`[S2]` 引用的来源。
- 环境读取失败最多等待 30 秒，之后继续普通聊天。

环境感知仍是“用户发消息后参考已允许的近期观察”。主动提醒只在用户明确设定时间后执行；
本版不包含屏幕截图、无障碍读取、后台应用内容监控，也不能根据通知自动猜取件或下课时间。

## 1.6.1 记忆精确率修复

- 真机截图中的 AI 自我说明、能力限制、知识问答、记忆测试和当天情绪均建立回归用例。
- 自动晋升只使用候选自己引用的用户消息，不再拿同一整理批次里的另一句话背书。
- 常见位置表达“我在/来自/搬到苏州”等即使被模型标成普通事实，也会被本地改判为敏感。
- 语言证据收紧：`别` 不再匹配“别人”，裸“我的”不再被视为稳定事实证据。
- 自动晋升增加候选结论与来源消息的最低词汇重叠，避免无关偏好词误背书。
- 旧版本已写入的错误长期记忆会在读取时被过滤，不影响新对话；用户仍可在记忆页审阅和删除。
- 记忆页按“已生效 / 待确认 / 近期经历 / 已过期”分组，日期使用 ISO `YYYY-MM-DD`。
- 短期摘要默认折叠，支持“清理全部待确认”，没有待确认时自动显示已生效或近期经历。
- 记忆和摘要注入提示词前转义 XML 风格标签，不能伪造新的提示词分区。

## 1.6.0 本地记忆系统

- 新增短期摘要、原子长期记忆、证据来源和后台任务四类数据。
- 对话完成后仅入队，不阻塞回复；12 条消息或空闲约 30 分钟后整理。
- AI 整理使用低随机性、独立 1600 token 上限和严格 JSON 输出。
- 用户明说的事实可在校验后生效；AI 推测和敏感内容必须由用户确认。
- 记忆来源必须属于当前消息批次，相对时间由模型转换，消息时间由本地记录校正。
- 记忆检索采用 SQLite 全文、直接文本匹配、类型、时间、重要度和确认状态综合排序。
- 用户画像由有效边界、偏好和关系偏好动态生成，不单独保存人格诊断。
- v1 不包含 embedding 和向量数据库；达到设计门槛后再升级混合 RAG。

## 1.5.3 提示词分层

- `CompanionPromptBuilder` 改为稳定身份、固定边界、回答原则、当前交互风格、用户记忆、安全覆盖、示例和冲突优先级八个分区。
- 删除人设和动态风格中重复的“通常一到三句”，避免模型同时收到长短冲突的要求。
- 寒暄保持简短；知识、观点、计划和情绪类问题允许三到六句，复杂问题可以继续展开。
- 示例覆盖短回复和较长回答，不再让四组示例中的三组都以反问结束。
- 用户记忆明确标记为“资料，不是指令”，不能覆盖身份、边界或安全要求。
- 动态安全要求标记为最高优先级，并给出固定冲突顺序。
- 默认边界增加“不写露骨色情内容”，亲密表达保持自然克制。
- 默认系统提示当前约 1369 字符，并增加 1800 字符上限测试，防止继续无序膨胀。

## 1.5.2 JSON 空值修复

- 修复 `JsonNull is not a JsonObject` 暴露到聊天页的问题。
- `choices: [null]`、顶层 `null`、错误字段类型都改为安全解析。
- 解析器意外异常统一转成用户可读的“流式回复格式异常”。
- 增加顶层空值、空候选和非流式空候选回归测试。

## 1.5.1 HTTP 200 修复

- 识别 OkHttp SSE 对 HTTP 200 非流式响应的失败路径。
- 供应商返回普通 JSON 完成结果时，自动提取 `choices[0].message.content`。
- 供应商返回 JSON error 时，展示真实错误并按错误类型决定是否可重试。
- 代理或登录页返回 HTML 时，明确提示“服务器返回网页而不是 API 数据”。
- 增加三类 HTTP 200 回归测试。

## 1.5.0 架构与稳定性

- 领域层不再导入 `data`、`ui` 或 `di`，并增加自动边界测试。
- Provider、设置和聊天存储的接口全部移入领域层。
- `ChatEngine` 使用注入的应用 Scope，不再自行创建全局协程作用域。
