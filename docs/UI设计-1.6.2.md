# 言语 1.6.2 UI 与交互调整

日期：2026-11-25  
目标：减少页面跳变、输入干扰和无意义信息占用，让聊天、设置与记忆维护更像一个连续的手机应用。

## 设计原则

1. **一次只突出一个主动作**：首次连接只展示连接任务；流式生成时发送键变停止键。
2. **导航有方向感**：聊天进入设置、设置进入记忆采用轻量横向推进和淡入，返回时反向。
3. **不抢用户滚动**：只有用户在底部或刚发送消息时才自动跟随最新回复。
4. **高频操作靠近拇指**：确认与删除改为底部 Action Sheet。
5. **先给上下文，再给细节**：记忆分区固定在滚动顶部，摘要默认折叠。

## 聊天页

- 首次进入保留一张欢迎说明；产生消息后自动移出，避免长期占用首屏。
- Header 隐私文案缩短为“本地加密 · 必要上下文会发送给 DeepSeek”，完整说明留在首屏卡片。
- 用户向上阅读历史时，流式回复不再强制把列表拉到底部。
- 用户发送新消息时自动回到最新；离开底部后出现“回到最新”胶囊按钮。
- 发送和停止合并为同一个圆形动作键，流式中原位切换图标与颜色。
- 消息列表使用 item placement 动画，新增消息不直接跳入。

## 设置页

- 首次没有 API Key 时只显示连接说明与连接表单。
- 对话手感、记忆、隐私和关于在连接成功后平滑展开，减少首次配置负担。
- 成功或错误提示使用展开/收起过渡。
- 删除 Key 与清空聊天从 AlertDialog 改为底部确认面板，危险按钮使用错误色。

## 记忆页

- “已生效 / 待确认 / 近期经历 / 已过期”筛选条固定在列表顶部。
- 没有待确认时自动选择已生效或近期经历，避免进入空白页签。
- 摘要默认四行折叠，需要时展开。
- 记忆卡片在筛选与数据更新时使用位置动画。
- 清空全部、忘记最近三天、清理待确认统一使用底部 Action Sheet。

## 验证

- 首次连接页不显示“对话手感”和“关于”。
- 已配置页面仍显示完整设置。
- 空聊天只显示一个发送主动作。
- 流式状态只显示停止动作。
- JVM/Robolectric、Compose instrumentation 和 Lint 必须全部通过。
