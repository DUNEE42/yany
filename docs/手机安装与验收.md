# 言语个人版：手机安装与验收

## 安装

APK：

```text
artifacts/yanyu-personal-1.8.0-debug.apk
```

SHA-256：

```text
5F13D7DF4D79A8C20ACBD352B88B925ECC87D713FD009B442FE74A7279CE29AF
```

1. 通过数据线、聊天软件或网盘把 APK 发到手机。
2. 点击 APK 安装。
3. 如果系统阻止安装，允许当前文件来源“安装未知应用”。
4. 安装后桌面会出现“言语”。

## 首次连接

1. 准备自己的 DeepSeek API Key。
2. 打开言语，输入 Key。
3. 模型保持 `deepseek-chat`，除非账号明确使用其他模型 ID。
4. 点击“测试并保存”。

常见错误：

| 提示 | 处理 |
| --- | --- |
| Key 无效 | 检查 Key 是否复制完整，是否已被删除 |
| 余额不足 | 登录 DeepSeek 控制台检查余额 |
| 找不到接口或模型 | 检查模型 ID |
| 请求太频繁 | 稍后重试，或检查供应商限流 |
| 网络连接中断 | 检查手机网络、代理或防火墙 |

## 验收

1. 发送“你好”。
2. 确认用户消息立即出现。
3. 确认回复逐字出现，而不是长时间空白。
4. 回复过程中点击停止，确认状态显示“已停止生成”。
5. 杀掉 App 再打开，确认历史消息仍然存在。
6. 打开右上角设置，不输入新 Key，直接点击“测试并保存”，确认原有 Key 仍可使用。
7. 失败后点击“重试”，确认用户消息不会重复出现。
8. 在设置中分别测试“清空聊天”和“删除 Key”，确认两者互不混淆。
9. 在设置页的“对话手感”分区调整随机性、亲近感和回复长度，确认重新打开设置后参数仍然保留。
10. 确认设置页可以滚动，系统返回键可以返回聊天；没有 Key 时不能直接进入聊天。
11. 确认聊天页显示“记录加密保存在本机 · 必要上下文和记忆整理会发送给 DeepSeek”，没有“仅保存在本机”的误导文案。
12. 输入“最近真的很累，我有点想死”，确认出现安全支持卡和现实援助信息。
13. 输入“我不想死，我只是不知道该怎么办”，确认不误触发危机卡。
14. 从 1.4.0 覆盖升级，确认原有聊天记录仍能打开，应用没有崩溃。
15. 若供应商返回 HTTP 200 异常，确认界面显示 JSON 错误、网页拦截或响应类型问题，而不是只有“HTTP 200”。
16. 若供应商事件包含空候选或空字段，确认不会显示 `JsonNull is not a JsonObject` 等 Kotlin 内部异常。
17. 连续发送至少 6 轮，打开设置中的“记忆”，确认后台整理状态、短期摘要或长期候选出现。
18. 为候选记忆执行确认、修改、拒绝和删除，确认列表和下一轮回复能够正确反映状态。
19. 关闭自动记忆后继续聊天，确认不会创建新的整理任务；点击“现在整理”仍可手动执行。
20. 执行“忘记最近三天”和“清空全部记忆”，确认原始聊天仍保留，清空后自动记忆暂停。
21. 从 1.5.3 覆盖升级到 1.6.0，确认 v4 数据库迁移成功且原有聊天仍能打开。
22. 从 1.6.1 覆盖安装 1.6.2，确认原有数据库、聊天和设置仍能打开。
23. 在记忆页确认出现“已生效 / 待确认 / 近期经历 / 已过期”四个分组；日期显示为
    `YYYY-MM-DD`。
24. 用“喜欢先听结论”“不喜欢被抢话”聊天，确认稳定偏好和边界能进入已生效。
25. 用“测试你记不记得”“滴水之交是什么意思”聊天，确认不会形成长期记忆。
26. 提到“我在苏州”“最近找工作受挫”，确认只进入敏感候选或近期经历，不自动画像化。
27. 提到“今天不想说话”，确认只在短期摘要中出现，不会形成永久事件。
28. 打开“近期经历”，确认经历显示有效期；到期后会进入“已过期”且不再注入聊天。
29. 在“待确认”中执行“清理全部待确认”，确认已生效记忆、短期摘要和原始聊天均保留。
30. 首次启动时确认只看到连接任务；“对话手感”和“关于”在连接成功后展开。
31. 在消息较多时向上滑动，确认流式回复不会抢回滚动位置；点击“回到最新”可恢复跟随。
32. 确认发送中只显示一个“停止生成”动作，停止后恢复为“发送”。
33. 打开记忆页并上下滚动，确认分类筛选条保持在顶部。
34. 打开删除或清空操作，确认使用底部面板而不是居中弹窗。
35. 从 1.6.2 覆盖安装 1.7.0，确认聊天、记忆、API Key 和设置仍保留。
36. 设置 → 环境感知，确认所有来源默认关闭。
37. 打开通知使用权，收到菜鸟或测试通知后，在来源列表选择允许。
38. 发送“我下课去吃饭，快递到了吗”，确认可参考已允许的包裹事件。
39. 关闭该通知来源，确认旧摘要不再进入聊天，也不再显示在当前观察列表。
40. 关闭通知使用权，确认所有通知观察立即失效。
41. 填写常用城市并开启粗粒度网络位置，询问天气，确认优先使用手动城市。
42. 配置启用 JSON 的 HTTPS SearXNG 地址，点击“测试连接”。
43. 发送“查一下今天的新闻”，确认最多 5 条来源且聊天显示实际引用。
44. 发送带验证码或私人叙事的搜索请求，确认不会原样发送到搜索服务。
45. 搜索服务返回空结果时，确认不会声称“已联网核实”。
46. 清除近期观察和来源记录，确认本地列表清空。
47. 从 1.7.0 覆盖安装 1.8.0，确认聊天、记忆、API Key 和环境设置仍保留。
48. 搜索需要联网的问题时，确认先显示“将发送的搜索词”；取消后只聊天，不请求 SearXNG。
49. 修改搜索词后确认，检查实际请求和回复引用使用修改后的查询。
50. 从 1.8.0 设置 → 提醒，首次点击“开启通知”并授权 Android 通知权限。
51. 新建一个 2–3 分钟后的提醒，退出言语，确认到点出现系统通知。
52. 点击通知，确认回到言语；点击“知道了”或滑动清除通知。
53. 新建提醒后删除规则，确认到原定时间不会再出现通知。
54. 重启模拟器或手机，确认未到期提醒仍会触发。
55. 选择过去时间、空提醒文字或关闭通知权限，确认无法保存并出现明确提示。
