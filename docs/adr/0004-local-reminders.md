# ADR-0004：本地确定性提醒

状态：Accepted  
日期：2026-11-25

## 背景

1.7.0 可以在用户主动聊天时参考已允许的通知，但不能在离开应用后主动提醒。
仅依靠模型判断“什么时候下课”或“什么时候该取快递”既不可验证，也容易把猜测包装成事实。

## 决策

- 提醒时间必须由用户明确输入。
- 调度完全在 Android 本机完成，AI 不参与规则执行。
- 规则使用 Android Keystore + AES-GCM 加密，不进入聊天数据库和模型上下文。
- 使用 `AlarmManager.setAndAllowWhileIdle`，不申请精确闹钟权限。
- Android 13+ 必须取得通知权限才能创建提醒。
- 重启和覆盖升级后恢复未到期规则。
- 删除规则必须同时撤销系统闹钟。

## 理由

- 可解释：用户知道提醒为何存在以及何时触发。
- 可纠正：用户随时可以删除规则。
- 隐私：提醒文字不需要离开手机。
- 稳定：网络、模型和供应商故障不影响本地调度。
- 合规：不依赖屏幕抓取、无障碍或后台读取其他应用内部状态。

## 后果

- 省电模式下可能延迟，属于已知限制。
- 不应宣传为“精确闹钟”。
- 用户必须主动管理通知权限。
- 自动从通知、课程或日历生成提醒属于后续独立能力，必须加入来源与确认环节。
